# Venues

Hand-maintained by Robert. The paper-writing skill reads this table when it
proposes a venue and fills the submission checklist; it never edits the file.
Every row below is an example placeholder for Robert to correct or delete; the
deadline patterns, page limits and review models are from memory and change
yearly, so check the call before relying on a row.

Fields: venue, kind (journal, conference, workshop, preprint), deadline pattern
(month or rolling), page limit (main text, in pages or words), review model
(single-blind, double-blind, open), notes (article types, statements the venue
requires, figure rules, preprint policy).

| Venue | Kind | Deadline pattern | Page limit | Review model | Notes |
| --- | --- | --- | --- | --- | --- |
| Bioinformatics (OUP) | journal | rolling | original paper about 7 pages; application note 2 pages | single-blind | example row; application notes need "Availability and implementation" statement with a public repository; software must be freely available to academics |
| PLOS Computational Biology | journal | rolling | no limit | single-blind, editor names published | example row; software articles and methods articles; data availability statement mandatory; CC-BY |
| Nucleic Acids Research, database issue | journal | September (issue in January) | about 8 pages | single-blind | example row; database and web server issues have fixed yearly calls; resource must be freely accessible |
| Journal of Biomedical Semantics | journal | rolling | no limit | single-blind | example row; ontology papers should cover the MIRO items; CC-BY, article processing charge |
| ISWC (International Semantic Web Conference) | conference | May (research track) | 15 pages LNCS plus references | double-blind | example row; resource track wants the resource public with a persistent URL and license; supplemental material allowed |
| ICBO (International Conference on Biomedical Ontology) | conference | April to June | 6 to 12 pages | single-blind | example row; CEUR proceedings; ontology must be public with a dereferenceable IRI |
| ECCB / ISMB (proceedings track in Bioinformatics) | conference | January (ISMB), March (ECCB) | about 8 pages | single-blind | example row; accepted papers appear in Bioinformatics; strict page limit at submission |
| NeurIPS | conference | May | 9 pages main text plus references and appendix | double-blind | example row; paper checklist mandatory and published; broader impacts and limitations expected |
| Nature Machine Intelligence | journal | rolling | about 3000 to 5000 words | single-blind | example row; reporting summary, code availability and data availability statements mandatory |
| bioRxiv / arXiv | preprint | rolling | none | none | example row; post before or at submission when the venue allows; record the preprint DOI in the plan |
